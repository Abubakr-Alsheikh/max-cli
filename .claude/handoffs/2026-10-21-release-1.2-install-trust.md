## What We Did

**1.2.0 features**

- **Compress to a size:** `--size 25MB` on `video compress` (bitrate from length, two-pass x264, one lower retry), `images compress` (quality search, then shrink; PNGs become JPEG or WebP) and `pdf compress` (lossless rewrite, then lower dpi steps). Fixed: same-stem images overwrote each other in folder batches.
- **`max video cut-silence`:** silencedetect, padding kept at each cut, `select`/`aselect` through a filter file (`-/filter_complex` on FFmpeg 7+).
- **`max audio transcribe`:** speech MP3, Gemini Files API (`core/engines/gemini_files.py`), `--prompt` for extra instructions; SRT from JSON cues because Gemini's own SRT timings were wrong.
- **Download part of a video:** `--start/--end/--exact-cuts` (`core/engines/download_section.py`); the Download page's PART card (link `t=` fills From, live length and size, PART tag and clock on the row); Options moved under Output.
- **Install and update:** Start Here guide (`docs/start-here.md`), `install.ps1`/`install.sh`, `max update` (uv receipt-aware; on Windows a hand-off window that waits for Max to close, because an in-place update broke the install), update notices after commands and in the dashboard (`UPDATE_CHECK`), `max doctor`, `python -m max_cli`.

**1.2.1 fixes**

- **FFmpeg installed nowhere:** the Windows link 404'd, evermeet.cx (macOS) closed its API, johnvansickle.com (Linux) stopped answering. Now winget/Homebrew first, then fallback sources each checked against its published SHA-256, ffprobe installed too, no traceback on failure.
- **Windows Defender refused the installer:** `install.ps1` piped uv's installer into `Invoke-Expression`. It now gets uv from winget or uv's zip (SHA-256 checked) and its text doesn't name the pattern. Guides lead with `winget install --id astral-sh.uv --exact` then `uv tool install max-cli`.
- **New page:** `docs/safety.md` ("Is Max Safe?"): what is installed from where, antivirus false positives, Protection history, reporting to Microsoft.

## Decisions Made

- **Merge only on the maintainer's "merge"**; installs and `pyproject.toml` edits need no asking (AGENTS.md section 6).
- **On Windows, winget is the trusted route** for both uv and FFmpeg; scripts never download and run other scripts.
- **Every download Max makes is checked against a published SHA-256** when the source publishes one (johnvansickle doesn't; it's the last Linux fallback).
- **Updates never replace a running Max on Windows**; they hand off to a window that waits (`updates.hand_off`).
- **Release flow:** `release_plan.py`, CHANGELOG section, `ci_local.py`, PR, merge, tag, check PyPI, `pip install -e . --no-deps` for the maintainer's copy.
