# PLANS

This folder contains project plans organized by status.

## Structure

```
PLANS/
├── active/       # Current tasks to work on
├── completed/    # Completed phase summaries
└── deferred/    # Deferred tasks with reasons
```

## Workflow

1. **Check PLANS/active/** for current tasks
2. Work on a task and mark complete in its file
3. Move completed plans to PLANS/completed/
4. Move deferred tasks to PLANS/deferred/
