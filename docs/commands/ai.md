# AI Commands

Max CLI supports multiple AI providers including local models via Ollama.

## chat

Interactive chat mode with AI.

```bash
max ai chat
```

## categorize

Categorize files using AI.

```bash
max ai categorize <directory>
```

## search

Semantic search for files.

```bash
max ai search "query" <directory>
```

## generate

Generate an image using AI.

```bash
max ai generate "a beautiful sunset"
```

## extract

Extract structured data from images.

```bash
max ai extract <image> -s "field:description"
```
