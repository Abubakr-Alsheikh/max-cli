# Commands

Max CLI provides these command groups:

- [Images](images.md) - Compress, resize, convert and strip images (`max images`)
- [Audio](audio.md) - Audio metadata, compression and noise removal (`max audio`)
- [Video](media.md) - Video and audio tools built on FFmpeg (`max video`)
- [Download](grab.md) - Download media from YouTube and other sites (`max grab`)
- [PDF](pdf.md) - Merge, split, compress, OCR and fill forms (`max pdf`)
- [AI](ai.md) - Ask, chat, analyze images, search and extract data (`max ai`)
- [Files](files.md) - Rename, sort, deduplicate, back up and undo (`max files`)
- [Queue](queue.md) - Run heavy jobs in the background (`max queue`)
- [Tools](tools.md) - QR codes and clipboard helpers (`max tools`)
- [Config](config.md) - API keys and settings (`max config`)
- [Dashboard](dashboard.md) - Interactive terminal dashboard (`max`, or `max dashboard`)

Run `max <group> --help` to see every command in a group, and `max <group> <command> --help` for its options.
